# 60-Second Version — Explain Supervised Learning

**Duration:** ~60 seconds
**Scenario:** Team meeting / Technical discussion

---

"Supervised learning is the most common approach in machine learning. The core idea is simple: we give the model a dataset where every example has both the input features and the correct output label. The model then learns a function that maps inputs to outputs by iteratively reducing its errors.

There are two main types: classification, where the output is a category — like spam or not spam — and regression, where the output is a continuous value — like predicting house prices. The training process involves splitting data into train, validation, and test sets, choosing a loss function to measure errors, and using optimization algorithms like gradient descent to update the model parameters.

The biggest practical challenge with supervised learning is getting high-quality labeled data. Data labeling is expensive and time-consuming. That's why in real-world projects, techniques like active learning, where you label only the most informative examples, and transfer learning, where you reuse pre-trained models, have become essential."
