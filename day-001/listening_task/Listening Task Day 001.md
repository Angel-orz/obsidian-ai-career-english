# 🎧 Listening Task — Day 001

## Recommended Content

**Source:** Andrew Ng — DeepLearning.AI

**Link:** Search "Andrew Ng Supervised Learning" on YouTube or visit deeplearning.ai

**Duration:** ~10 minutes

---

## 🎯 What to Listen For

1. **How Andrew defines supervised learning** — He uses the house price prediction example. Pay attention to how he transitions from the simple example to the formal definition.

2. **The distinction between classification and regression** — Listen for the key words that signal which type of problem is being discussed. Classification words: "categories," "classes," "discrete." Regression words: "continuous," "predict a number," "value."

3. **The pronunciation of technical terms** — Andrew speaks clearly. Notice how he pronounces:
   - "Supervised learning" → /ˈsuːpərvaɪzd ˈlɜːrnɪŋ/
   - "Features" → /ˈfiːtʃərz/
   - "Training set" → /ˈtreɪnɪŋ set/
   - "Hypothesis" → /haɪˈpɒθəsɪs/

4. **How he explains the learning process** — He describes it as giving the algorithm a dataset where the "right answers" are given. This is the simplest, most interview-ready explanation.
