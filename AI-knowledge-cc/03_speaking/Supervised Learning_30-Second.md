# 30-Second Version — Explain Supervised Learning

**Duration:** ~30 seconds
**Scenario:** Elevator pitch / Quick introduction in a meeting

---

"Supervised learning is a machine learning approach where we train models using labeled data. Think of it like teaching a child with flashcards — you show an example and provide the correct answer. The model learns the mapping from input to output by minimizing its prediction errors. It's the most widely used ML paradigm, powering everything from spam filters to medical diagnosis systems."
