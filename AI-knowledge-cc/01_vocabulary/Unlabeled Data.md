# Unlabeled Data

## Definition (English)
Unlabeled data is data that contains only input features without corresponding target outputs or labels. It is the primary input for unsupervised learning algorithms.

## Chinese
无标签数据 — 仅包含输入特征而没有对应目标输出或标签的数据，是无监督学习算法的主要输入。

## German
die unbeschrifteten Daten

## Intuition
Think of a box of old photographs with no names or dates written on the back. You can still group them by scene (beach, mountains, city) or by who appears in them — but there are no "correct answers" telling you how to categorize them. That's unlabeled data.

## Example
A social media platform collects millions of user posts without any category tags. Using topic modeling (an unsupervised technique), they can automatically discover themes like "sports," "politics," and "entertainment" from the text content alone.

## Spoken Version
"Unlabeled data is the raw material of unsupervised learning — it has features but no ground truth labels, so the algorithm has to discover patterns on its own."

## German Workplace Example
"Im Gegensatz zu überwachtem Lernen arbeiten wir hier mit unbeschrifteten Daten — das Modell muss die Muster selbstständig erkennen."
