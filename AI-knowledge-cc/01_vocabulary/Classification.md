# Classification

## Definition (English)
Classification is a type of supervised learning where the model predicts a discrete category (class label) for each input. The output is one of a finite set of possible classes — for example, "spam" or "not spam," "cat," "dog," or "bird."

## Chinese
分类

## German
die Klassifikation (die Klassifizierung)

## Intuition
Imagine sorting emails into folders: inbox, spam, promotions. A classification model learns the rules for sorting by seeing thousands of labeled examples. Unlike regression which predicts a number, classification answers "which bucket does this belong to?" The key difference from regression is that the output space is discrete — there's no meaningful "between" two classes.

## Example
A medical diagnosis system classifies X-ray images into three categories: "normal," "pneumonia," or "tuberculosis." The model outputs a probability distribution across the three classes, and the highest-probability class is selected as the prediction.

## Spoken Version
"In classification tasks, the model outputs a discrete label rather than a continuous value — it answers 'which category' rather than 'how much.'"

## German Workplace Example
"Bei Klassifikationsaufgaben gibt das Modell eine diskrete Kategorie aus, keinen kontinuierlichen Wert. Es beantwortet die Frage 'welche Kategorie' und nicht 'wie viel'."
