# Regression

## Definition (English)
Regression is a type of supervised learning where the model predicts a continuous numerical value. Unlike classification which outputs a category, regression outputs a number along a spectrum — for example, predicting house prices ($245,000), temperature (23.7°C), or stock returns (2.3%).

## Chinese

## German

## Intuition
Think of drawing a line through scattered data points on a graph. Regression finds the mathematical relationship between input variables and a continuous output. If classification is sorting photos into "cat" and "dog," regression is predicting the exact weight of the animal from its measurements. The goal is to minimize the distance between predicted and actual values.

## Example
A real estate model predicts apartment sale prices based on features: square meters, number of rooms, floor level, and neighborhood. The output is a continuous euro amount — €450,000, not "expensive" or "cheap." The loss function (e.g., MSE) measures how far off the predictions are in euros.
