# Sequential Data

## 是什么
Data where the order of elements matters — changing the sequence changes the meaning. Text, audio, time series, and video are all sequential. Unlike tabular data where rows are independent, sequential data has dependencies across time steps.

## zh / de
序列数据 / sequenzielle Daten

## 记住它
> "The sentence 'dog bites man' means something very different from 'man bites dog' — same words, different order. That's why we need special models like RNNs and Transformers for sequential data."

## 说
Sequential data requires models that can capture order dependencies — RNNs do this step by step, while Transformers use attention to look at all positions at once.
