# Listening Task — Unsupervised Learning

## Recommended Content

**Source:** Andrew Ng — DeepLearning.AI

**Video:** "Unsupervised Learning" (from Machine Learning Specialization, Course 1, Week 1)

**Link:** Search "Andrew Ng Unsupervised Learning" on YouTube or visit deeplearning.ai

**Duration:** ~8 minutes

---

## What to Listen For

1. **How Andrew contrasts unsupervised with supervised learning** — He uses the difference between "right answers given" vs "no right answers." This is the simplest, most interview-ready distinction.

2. **The clustering example** — Andrew uses the Google News example: grouping news articles by topic without pre-labeling. Pay attention to how he describes the algorithm "finding structure" on its own.

3. **The cocktail party problem** — He mentions separating mixed audio signals as an example of unsupervised learning. This is a memorable, concrete example to use in interviews.

4. **Pronunciation of key terms:**
   - "Unsupervised learning" → /ʌnˈsuːpərvaɪzd ˈlɜːrnɪŋ/
   - "Clustering" → /ˈklʌstərɪŋ/
   - "Cocktail party problem" → /ˈkɒkteɪl ˈpɑːrti ˈprɒbləm/
